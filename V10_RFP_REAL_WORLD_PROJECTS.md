# V10 — RFP + real-world project experience

Member projects now begin with a full RFP-style engineering brief instead of only an analytical model.

## Added to all 45 projects
- Industry-inspired real-world problem and stakeholder
- Why the problem matters
- RFP scope
- Explicit numerical success criteria
- Required work products
- Hardware validation plan
- Stretch analysis
- Portfolio/interview framing
- Suggested honest portfolio summary based on the user's final modeled result

The analytical engines are unchanged; the new brief makes the model part of a larger engineering decision process.

Portfolio language intentionally uses terms such as “analytically designed,” “modeled,” and “developed a concept” so users do not misrepresent a guided project as paid industry work or tested hardware.

## Animated requirement score
Running **RFP check** now shows an animated on-screen score such as **3 out of 4 tests passed**. Partial results use amber/orange styling; the score only turns green when every modeled analytical requirement passes. The detailed compliance panel below the model shows the same pass count and progress bar.
